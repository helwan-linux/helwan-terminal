# Helwan Terminal Commands Guide

This document provides a comprehensive guide to commands available in the Helwan Linux terminal across multiple languages (English, Arabic, Spanish, and Chinese).

---

## 1. version / الإصدار / versión / 版本
* **Description:** Show Helwan Linux distribution information.
* **Syntax:** `version`
* **Examples:**
  * **English:** `version`
  * **العربية:** `الإصدار`
  * **Español:** `versión`
  * **中文:** `版本`

* **Syntax:** `sync`
* **Examples:**

  * **Español:** `sincronizar`
  * **中文:** `同步`

## Notes

- Commands are available in English, Arabic, Spanish, and Chinese.
- System commands and parameters such as `status`, `restart`, and `enable` remain unchanged.
- Helwan Terminal uses native Pacman and Yay tools for package management.
